# 谁在驱动谁

环境生态学课程交互展示：生成式 AI 协作中的共生边界与人的主体性。

打开 `index.html` 即可使用，无需安装依赖。页面展示本组问卷的总体平滑趋势和四段均值，并提供滑杆观察与 22 项即时测试。

## 数据与隐私

- 原始问卷共 100 份；按完成时间少于 30 秒的预设规则筛去 14 份，汇总 86 份。该规则不等于证明单份答卷无效。
- 公开仓库只含 81 个汇总趋势节点、4 组均值与问卷题目，不含个体作答、原问卷序号或个体 X/H/E/Y 分数。
- 即时测试在访问者自己的浏览器内计算。页面没有网络提交接口，测试答案不上传、不写入仓库；刷新页面即可清空。
- 趋势与分区用于课堂讨论，不构成个人能力诊断，也不能证明 AI 参与程度与协作状态之间存在因果关系。

## 文件

- `index.html`：页面入口
- `styles.css`：样式
- `app.js`：图表与测试交互
- `data.js`：匿名汇总数据及问卷题目
- `check.cjs`：本地自检；使用 Node.js 运行 `node check.cjs`

公开版为保护受访者隐私，移除了本地研究版的个体散点及基于个体数据的三个滑杆估计，只保留沿总体趋势观察的 AI 参与程度滑杆。
